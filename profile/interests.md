## 我是谁
研二学生，2027 年 5 月毕业，目标是 AI 方向的研究/工程岗位。需要既跟上行业热点，又能把关键论文讲清楚（面试）、用得上（项目）。

## 核心方向（高权重，core_score 主要看这里）
1. **LLM / Agent / RAG**：大模型推理与后训练（RLHF、DPO、GRPO、on-policy distillation）、智能体（规划、记忆、工具调用、多智能体、agent 评测与安全）、检索增强、长上下文、评测基准。
2. **多模态 / CV**：视觉语言模型（VLM）、图像/视频/音频生成（diffusion、自回归）、3D 与具身（VLA、导航、机器人）。
3. **训练与系统**：预训练配方与架构（MoE、线性注意力、稀疏注意力）、分布式训练、推理加速（量化、KV cache、投机解码）、模型压缩、微调方法（LoRA 系列）。

## 加分项
- 有开源代码 / 权重，能复现
- 方法有可迁移性（不只是刷一个榜）
- 论文写得清楚、有好的架构图

## 减分项
- 纯 benchmark 刷分、改进幅度小
- 没有代码、没有细节的"技术报告"
- 与 AI 无关的项目（哪怕在 GitHub Trending 上）：教程合集、awesome 列表、网页模板、游戏、桌面工具等
- 单纯的 API 封装 / 套壳客户端
